## ما هى javascript ؟

![شعار لغة javascript](/assets/image/javascript/javascript.svg){: .mt-4 .mb-4 .w-20}

JAVASCRIPT عبارة عن محرك أو عقل أى موقع ليه بسبب أن الموقع بدون javascrip عبارة عن صورة والمستخدم ميعرفش يتفاعل مع الموقع مثال: عرض القائمة أو الضغة على زرار معين فيفتح نافذة صغيرة للمستخدم, دا مثال بسيط عن استخدام اللغة

## تاريخ اللغة
اللغة ظهرت سنة 1995 فى شركة Netscape, المهندس اللى عمل اللغة هو بريندان آيخ (Brendan Eich) كتب اللغة فى 10 أيام, أسم اللغة ليس له علاقة بلغة Java واسمها الاول Mocha ثم الى LiveScript واستقرو على Javascript للاستفادة من شهرة Java فى ذالك الوقت مع أن اللغتين مختلفتين تماماً

## إصدارات اللغة
فى سنة 1997 ظهور الاسم التقنى ECMASCRIPT وفى سنة 1999 صدرت النسخة الثالثة ES3 واللغة يتم اصدار جديد كل عام تحت مسمى ECMAscript 

## كيف تشغل اللغة
تقدر تشغلها فى المتصفح من ادوات المطور معظم المتصفحات لديها هذه الادوات developer tool فى console تقدر تكتب كود javascript زى كدة 
```javascript
console.log("hello from console developer tool");
```
